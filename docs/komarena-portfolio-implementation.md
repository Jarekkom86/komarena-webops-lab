# KomArena profesionálne portfólio

## Rozsah

Samostatná WordPress šablóna `KomArena – Portfólio` prezentuje štyri overiteľné projekty v štruktúre problém, vykonaná práca, nástroje, výsledok/aktuálny stav a relevantné odkazy. Text zámerne neuvádza neoverené metriky ani definitívnu dokončenosť priebežne rozvíjaných projektov.

## Bezpečné nasadenie

1. Vytvoriť staging alebo úplnú zálohu pluginu.
2. Nahrať novú verziu pluginu a nechať ju deaktivovanú, kým nebude pripravený staging.
3. Vytvoriť bežnú WordPress stránku so slugom `portfolio` a priradiť šablónu `KomArena – Portfólio`.
4. Overiť desktop a mobil, všetky odkazy, hlavičku, pätičku a konzolu prehliadača.
5. Overiť, že košík, checkout, účet, platba a doprava sú bez zmeny.
6. Až po kontrole pridať stránku do hlavného menu. Pri probléme vrátiť predchádzajúci ZIP pluginu alebo deaktivovať plugin.

## Otvorené body pred produkciou

- Doplniť fotografie alebo screenshoty projektov iba po potvrdení práv a aktuálnosti.
- Potvrdiť, či verejný odkaz na internú dokumentáciu JARO OS má zostať v portfóliu.
- Rozhodnúť, či sa portfólio prelinkuje aj z pätičky a homepage.
- Skontrolovať formulácie projektu inteligentnej vírivky s vlastníkom; technické schémy ani 230 V postupy sa nezverejňujú.
